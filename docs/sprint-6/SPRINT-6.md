# Sprint 6 — Integration & Polish

## Objetivo
Integrar todos os componentes em um fluxo end-to-end coeso, adicionar system tray, installer, e otimizar performance para o target de < 2s de latência.

## Entregável
Aplicação completa, instalável, com todos os fluxos funcionando end-to-end, pronta para uso pessoal diário.

## Critérios de Aceite
- [ ] Fluxo completo funciona: abrir → configurar → iniciar reunião → transcrever → sugerir → salvar
- [ ] System tray com menu de contexto
- [ ] Installer funcional (.exe ou .msix)
- [ ] Latência end-to-end < 2s (p95)
- [ ] Sem memory leaks após 2h de uso
- [ ] Startup time < 5s
- [ ] Documentação de uso
